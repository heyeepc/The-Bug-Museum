## 🐞 Bug 描述

在实现“按利润分段计算奖金”的程序时，输出结果异常（数值错误或不稳定）。

---

## 🔍 问题分析

代码中在 `scanf` 输入利润之前，就使用变量 `i` 参与了奖金计算：

```c
double i;
double a = i * 0.1;
```

此时 `i` 尚未被赋值。

---

## 💥 根本原因

使用了**未初始化变量（Uninitialized Variable）**。

在 C 语言中，局部变量不会自动初始化，其值是**未定义的随机值（垃圾值）**。
在变量赋值之前使用它，会导致：

* 计算结果不可预测
* 程序行为不稳定

---

## ✅ 修复方案

将所有依赖 `i` 的计算放到 `scanf` 之后：

```c
scanf("%lf", &i);

double a = i * 0.1;
```

或者更好的做法是：**只在需要时计算，避免冗余变量**：

```c
if (i <= 100000){
    bonus = i * 0.1;
}
```

---

## 🧠 经验总结

* 任何变量在使用前必须确保已经初始化
* 输入数据（`scanf`）必须早于所有依赖该数据的计算
* 避免“提前计算”，尽量在逻辑分支中按需计算
* 这是典型的“执行顺序错误（Execution Order Bug）”
